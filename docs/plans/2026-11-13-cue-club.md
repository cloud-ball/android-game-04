# Cue Club (8-ball vs CPU) — build plan

Branch `cue-club`. Research: docs/research/Cue Club pool game design.md (+ notes). Design doc:
docs/games/pool.md (updated with the research's 15 changes). The game stays `enabled = false` until done.

## Milestones
1. **Physics core (shared/cue_sim)** — this step.
   - CueParams (constants), CueTable (7-ft 1.981 x 0.991 m playfield, long axis vertical; rails,
     facings, jaw points, capture circles), CueSim (16 balls in PackedFloat64Array state; phases
     sliding / rolling / spinning / stationary with closed-form motion; fixed 1/240 s substeps with
     swept time-of-impact events in time order, ties by index, max 64 events per substep; ball-ball
     impulse with friction capped at m|s|/7; Han 2005 cushions from pooltool's corrected source;
     capture-circle pockets; cue strike with tip offset, no squirt / swerve / masse / jump).
   - Shot log for the rules: first ball hit, cushion contacts after first contact, pots by pocket.
   - games/pool/logic/pool_rack.gd: standard rack with seeded 0-0.2 mm jitter.
   - Tests (9 physics): energy never increases, stun slide->roll timing and 5/7 speed, draw-back
     speed 2/7 R w, 90-degree rule, 30-degree rule, outside gearing english ~0 throw, no overlaps over
     random shots, golden-master break, step-rate independence. Stop shot at <= 1.5 m/s.
   - Benchmark (shared/cue_sim/cue_bench.gd, Boot --bench=cue): us per substep, ms per full shot,
     break hash; run on desktop and the Vivo. Decides the CPU budget and per-platform goldens.
2. **Rules (games/pool/logic)** — pure Casual 8 state machine (20 rules, shot-start snapshot), 40 tests.
3. **Table view + controls** — MultiMesh balls with one object-space shader, painted table, 22 deg
   KEEP_WIDTH camera; angular-drag aim, left fine-aim strip, right power bar (v = vmax p^2, 8 / 12 m/s),
   spin panel, ball in hand, solver-driven guideline; HUD on GameShell; how-to cards.
4. **CPU** — prune with analytic pot probability, ~10 / 40 / 100 rollouts at 1/120 s on worker
   threads, Gaussian aim noise 0.6 / 0.26 / 0.12 deg, precomputed breaks, self-play tuning (400 games).
5. **Polish + phone pass** — sounds, haptics, camera moves after release, reduce motion, store shots.
