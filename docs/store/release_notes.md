# Release notes ("What's new", ≤ 500 characters per language)

## v0.2.0 (version code 1): first closed-test release
Three original games against the CPU:
• Serpent Grid: a snake duel on a neon grid
• Facetfall: a falling-gem race in a crystal tower
• Break & Bank: eight-ball billiards with real ball physics
Three difficulty levels, a daily challenge, coins and best scores. Offline, no ads.
Thank you for testing! Tell us what felt great and what didn't.
